# Secure Linux Web Infrastructure

Този проект демонстрира изграждането на защитена, автоматизирана Linux уеб инфраструктура в изолирана KVM (Kernel-based Virtual Machine) среда. Проектът е подходящ за портфолио за позиции на начално ниво (Junior SysAdmin / Entry-level DevOps).

## 🚀 Архитектурни компоненти & Постижения

1. **Мрежова база (KVM & Ubuntu):**
   * Конфигуриране на виртуална машина с Ubuntu Server в KVM среда.
   * Тестване и верификация на мрежовата свързаност (`ping`, `curl`) и управление на достъпа.

2. **Сигурност и Защитна стена (UFW):**
   * Имплементиране на стратегия за сигурност "Забранено по подразбиране" (`Default Deny incoming`).
   * Ограничаване на външния достъп само до задължителните портове: **Порт 22 (SSH)** за отдалечена администрация и **Порт 80 (HTTP)** за уеб трафик.

3. **Уеб сървър (Nginx):**
   * Инсталация и конфигурация на високопроизводителен уеб сървър Nginx.
   * Локално и мрежово тестване на клиент-сървър архитектурата.

4. **Автоматизация (Bash Scripting):**
   * Създаване на автоматизиран скрипт за архивиране (`backup.sh`) с абсолютни пътища.
   * Пакетиране и компресиране (`tar -czvf`) на уеб съдържанието (`/var/www/html`) и критичните системни логове на Nginx (`/var/log/nginx`).
   * Динамично генериране на уникални имена на архивите на база текущата дата (`$(date +%Y-%m-%d)`).

## 🛠️ Детайли по Имплементацията

### 1. Проверка и Конфигурация на Защитната стена (UFW)
След инсталацията на Nginx, защитната стена блокира външния достъп. Правилото за HTTP трафик беше добавено успешно:
```bash
sudo ufw status verbose
sudo ufw allow 80/tcp
```

### 2. Скрипт за Автоматичен Бекъп (`backup.sh`)
Скриптът е разположен в `~/scripts/backup.sh` с дадени права за изпълнение (`chmod +x`). 

```bash
#!/bin/bash

# Дефиниране на променливи с абсолютни пътища
SOURCE_DIR="/var/www/html"
LOG_DIR="/var/log/nginx"
READY_MADE_ARCHIVES="/home/ubuntu/backups"
BACKUP_FILE="backup-\$(date +%Y-%m-%d).tar.gz"

# Създаване на дестинацията, ако не съществува
mkdir -p \$READY_MADE_ARCHIVES

# Архивиране и компресиране на уеб файловете и системните логове
tar -czvf \(READY_MADE_ARCHIVES/\)BACKUP_FILE \(SOURCE_DIR\)LOG_DIR
```
